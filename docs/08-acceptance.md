## 2. 结论等级

| 等级 | 含义 |
|---|---|
| **阻断（Blocker）** | 核心闭环不可用、数据串用户、任务状态由前端伪造、容器无法启动、CI 失败、提交密钥 |

## 4. 后端验收清单

### 4.1 身份与会话

- [ ] 正确账号登录 200，返回 accessToken 与用户；Cookie 含 HttpOnly、SameSite=Lax、Path=/api/auth。
- [ ] 错误密码/不存在账号/禁用账号统一 401 `INVALID_CREDENTIALS`，不泄露存在性。
- [ ] 连续失败 5 次触发 429，带 `Retry-After`；成功后计数清零。
- [ ] accessToken 过期返回 401 `TOKEN_EXPIRED`；损坏/篡改返回 `TOKEN_INVALID`。
- [ ] 刷新接口用 Cookie 换取新 accessToken；退出后同一刷新令牌不可再用。
- [ ] 受保护接口无令牌 401；USER 访问 `/api/admin/**` 403。
- [ ] 访问他人任务/素材/结果均 404，不返回 403 或数据。

### 4.2 模板与素材

- [ ] 模板列表只返回上架模板；分类筛选正确；未知分类返回空列表。
- [ ] 模板详情字段完整（数量、MIME、大小、画布、封面、`kind`、`effectTags`、`output`）。
- [ ] 图片模板详情返回效果标签；视频模板返回 `durationMs`、分辨率与 `hasAudio`。
- [ ] 坏 `render_spec` 的模板读取/提交返回 500 `TEMPLATE_SPEC_INVALID`，不产生任务。
- [ ] 上传合法 JPEG/PNG 201；落盘路径为服务端生成，无原始文件名。
- [ ] 伪装图片 422；非 JPEG/PNG 415；超限 413；像素炸弹拒绝。
- [ ] 规范化后的图片方向正确、无 EXIF、尺寸在限制内。
- [ ] 删除未绑定素材 204；已绑定 409；他人素材 404。
- [ ] 素材内容需鉴权；公开目录无法直接访问素材/结果。

### 4.3 任务与异步

- [ ] 提交返回 202 + Location；任务 QUEUED，三步 PENDING，素材顺序正确，`retry.maxAttempts` 为配置快照。
- [ ] 相同 `clientRequestId` 重复请求只建一个任务，返回 200 + `Idempotent-Replay: true`；同键不同载荷 409，不建任务。
- [ ] 数量不符/重复素材/他人素材/下架模板分别返回 400/404，不建任务。
- [ ] worker 认领后任务 RUNNING；步骤按 seq 依次执行；每步有开始/结束时间与 attempt 记录。
- [ ] 成功：三步 SUCCEEDED，结果文件存在、尺寸正确、任务字段完整。
- [ ] 可重试失败：`RETRYING`、`nextRetryAt`、`retryCount+1`；到期重新认领并生成新 attempt。
- [ ] 重试成功：失败步骤变为 SUCCEEDED，历史 attempt 保留；前序成功步骤不重跑。
- [ ] 重试耗尽：任务 FAILED，当前步 FAILED，后续 SKIPPED，attempt 数等于上限。
- [ ] 永久失败注入（`retryable=false`）：失败码/阶段匹配，`failure_simulated=1`，不进入 `RETRYING`。
- [ ] 失败后不再执行后续阶段；重复查询不推进。
- [ ] 注入次数按每次进入阶段消费；同一任务重试会再次消耗；下一次任务正常。
- [ ] 启动恢复：RUNNING → QUEUED；attempt INTERRUPTED；step PENDING；`resumeCount+1`；不消耗重试预算。
- [ ] 恢复后续跑从第一个非 SUCCEEDED 步骤开始；已成功步骤时间戳与结果不变。
- [ ] 两个 worker 不重复执行同一任务；多任务结果互不覆盖。
- [ ] 查询接口无副作用；终态不会被改回 RUNNING/RETRYING。
- [ ] 结果未就绪 409；成功后返回 image/jpeg，ETag/304 正常。
- [ ] 视频任务成功返回 `video/mp4`、`Accept-Ranges: bytes`；`Range: bytes=0-99` 为 206 + 100 字节；poster 为 JPEG。
- [ ] 视频任务失败码（`VIDEO_RENDER_FAILED` / `VIDEO_TIMEOUT` / `VIDEO_OUTPUT_INVALID`）按 06/02 的重试语义处理；缺 ffmpeg 提交返回 503。

## 11. 阻断项

出现任一项，不得提交：

1. 容器无法从干净环境启动，或需要手工建表/导入 SQL。
2. 任务状态由前端定时器/本地状态推进，刷新后丢失或回退。
3. 查询失败把任务标记为失败。
4. 用户可以读取/修改他人任务、素材或结果。
5. 三步可乱序、并行，或失败后仍执行后续步骤。
6. 上传素材只存在浏览器临时地址，服务端无法读取。
7. 成功任务没有真实结果文件，或结果路径可公开猜测。
8. 同一 `clientRequestId` 的重复/并发提交产生多个任务，或重放返回 500。
9. 服务重启把 `RUNNING` 任务直接判失败，或续跑重跑已成功步骤。
10. 可重试失败无限重试，或重试等待阻塞 worker 线程。
11. 切换语言后仍显示旧语言且无法恢复，或缺翻译时页面出现空白/键名。
12. CI 失败；后端无步骤/失败测试；前端无多任务/查询异常测试。
13. 仓库提交 `.env`、真实密钥、真实用户照片或数据库文件。
14. README 缺少启动、配置、演示、身份、限制、AI 使用说明。
