# 06 · 前端视觉、组件与页面规范

> 本文是前端实现与视觉验收的唯一依据。参考截图在 [assets/reference](assets/reference)：UI-01 列表、UI-02 详情/上传、UI-03 处理中与历史、UI-04 账号。
> 目标不是逐像素复刻，而是保留其**布局与信息层级**，并用更完整的暗房视觉系统提升质感。实施顺序、逐页对照与偏差登记见 [11-development-plan.md](11-development-plan.md#5-页面实施与参考图对齐)。

## 1. 设计主张

**暗房画廊（Darkroom Gallery）**：界面是深色墙面，照片是唯一的主角，橄榄绿是暗房里的一束安全光。

三条原则：

1. **照片优先**：模板封面与结果图占据最大面积；文字、边框、按钮退到背景，不与图片争抢。
2. **克制的高光**：全站只有一个强调色（橄榄柠檬绿）。它只出现在主按钮、选中分类、处理中状态与焦点环；其余全部是暖灰与墨黑。
3. **可读的状态**：每个异步状态同时用**图标 + 文案 + 颜色 + 结构**表达，绝不只靠颜色或一个转圈。

避免：紫色渐变、霓虹发光、玻璃拟态叠满、过度圆角、emoji、假百分比、无意义的动效、把参考图的 credits/会员/账单照搬进来。

关键词：`暗房` · `留白` · `胶片颗粒` · `橄榄光` · `编辑感`

## 3. 设计 Token

### 3.1 颜色

```css
:root {
  /* 背景与表面：暖黑，不用纯黑，避免与照片死黑粘连 */
  --bg:              #0A0A0B;
  --bg-elevated:     #121214;
  --surface:         #17171A;
  --surface-2:       #1D1E1A;   /* 带一点橄榄暖调 */
  --surface-hover:   #22231E;

  /* 线条 */
  --border:          rgba(244, 244, 239, 0.08);
  --border-strong:   rgba(244, 244, 239, 0.16);

  /* 文字 */
  --text:            #F4F4EF;
  --text-secondary:  #B0B0A7;
  --text-muted:      #7E7E76;
  --text-disabled:   #5B5B55;

  /* 唯一强调色：橄榄柠檬 */
  --accent:          #C4E552;
  --accent-hover:    #D2F06A;
  --accent-pressed:  #A9C93B;
  --accent-ink:      #15170A;   /* 强调色上的文字 */
  --accent-soft:     rgba(196, 229, 82, 0.10);
  --accent-border:   rgba(196, 229, 82, 0.36);

  /* 语义色：低饱和、偏暖，避免交通灯感 */
  --success:         #8FD9A8;
  --success-soft:    rgba(143, 217, 168, 0.10);
  --warning:         #E7C66B;
  --warning-soft:    rgba(231, 198, 107, 0.10);
  --danger:          #FF8A80;
  --danger-soft:     rgba(255, 138, 128, 0.10);
  --info:            #9CB8E8;
  --info-soft:       rgba(156, 184, 232, 0.10);
}
```

使用规则：

- 主按钮：`--accent` 渐变 + `--accent-ink` 文字；**不要**在强调色上放白字（对比不足）。
- 选中分类：`--accent-soft` 背景 + `--accent` 文字/边框；主 CTA 才使用满色强调。
- 处理中：`--accent`；等待重试 / 恢复：`--warning`；成功：`--success`；失败：`--danger`；查询异常：`--warning`；排队：`--text-secondary`。
- 大面积背景只允许 `--bg` / `--bg-elevated` / `--surface`；不要整页铺强调色。
- 语义色不得用作装饰；只用于状态。

### 3.2 字体

| 用途 | 字体 | 规格 |
|---|---|---|
| UI / 正文 | Inter Variable（本地打包，OFL） | 400 / 500 / 600 |
| 中文 | 回退 `HarmonyOS Sans SC`、`PingFang SC`、`Microsoft YaHei`、`Noto Sans SC` | 不额外下载中文字体 |
| 数字 / 任务短码 / 时间 | JetBrains Mono（本地打包，OFL） | 400 / 500，`tabular-nums` |

```css
--font-sans: "Inter Variable", "HarmonyOS Sans SC", "PingFang SC",
             "Microsoft YaHei", "Noto Sans SC", sans-serif;
--font-mono: "JetBrains Mono", ui-monospace, SFMono-Regular, monospace;
```

字体以本地文件自托管：`frontend/src/assets/fonts/InterVariable.woff2`、`JetBrainsMono-Regular.woff2`，随 `OFL.txt` 入库，使用 `next/font/local` 加载；构建与运行均不依赖 Google Fonts/CDN。后端结果图水印另打包 `Inter-SemiBold.ttf`，与前端字体互不依赖。

字号阶梯：

| Token | 字号/行高 | 字重 | 用途 |
|---|---|---|---|
| `display` | 44 / 48 | 600 | 列表页主标题（桌面） |
| `h1` | 32 / 38 | 600 | 页面标题 |
| `h2` | 22 / 30 | 600 | 区块标题 |
| `h3` | 16 / 24 | 600 | 卡片/弹层标题 |
| `body` | 14 / 22 | 400 | 正文 |
| `body-strong` | 14 / 22 | 500 | 按钮、强调 |
| `small` | 13 / 20 | 400 | 辅助信息 |
| `micro` | 12 / 18 | 500 | 标签、时间、错误 |
| `eyebrow` | 11 / 16 | 600 | 大写英文眉题，字距 0.14em |

- 中文段落行高 ≥ 1.7；标题 1.25～1.35。
- 英文正文行高 1.5～1.6；按钮与标签使用 500/600 字重，避免全大写长句。
- 英文标题/按钮比中文长约 20%～40%：卡片标题最多两行，CTA 使用固定高度并允许换行但不撑破容器；顶栏导航禁止换行。
- 大标题字距 `-0.02em`；中文标题不要用过细字重（≤ 300 在小字号发虚）。
- 数字统一 `font-variant-numeric: tabular-nums`，避免状态时间跳动；日期与数字用 `Intl` 按语言格式化。

### 3.3 间距、圆角、阴影、动效

```css
--space-1: 4px;  --space-2: 8px;  --space-3: 12px; --space-4: 16px;
--space-5: 20px; --space-6: 24px; --space-8: 32px; --space-10: 40px;
--space-12: 48px; --space-16: 64px;

--radius-xs: 8px; --radius-sm: 10px; --radius-md: 14px;
--radius-lg: 20px; --radius-xl: 28px; --radius-full: 999px;

--shadow-panel: 0 30px 80px -40px rgba(0, 0, 0, 0.9);
--shadow-card:  0 18px 40px -28px rgba(0, 0, 0, 0.9);
--ease-out:     cubic-bezier(0.22, 1, 0.36, 1);
--dur-fast:     140ms;
--dur-base:     200ms;
--dur-slow:     320ms;
```

- 页面水平内边距：≥1280 为 48px；768～1279 为 32px；<768 为 20px。
- 内容最大宽度 1440px，居中。
- 卡片间距 20px；区块间距 48～64px；面板内边距 24～28px。
- 只使用柔和阴影，不叠加多层发光。
- 动效只做位置/透明度/图片缩放；禁止持续旋转的装饰动画。

背景质感（可选但推荐）：在 `body::before` 叠加 3% 的程序化细颗粒（SVG feTurbulence），`pointer-events:none`；顶部左侧加一层 6% 的橄榄径向光晕。必须不影响文字对比与滚动性能。

### 3.4 Tailwind 映射

```css
@theme inline {
  --color-bg: var(--bg);
  --color-surface: var(--surface);
  --color-text: var(--text);
  --color-muted: var(--text-muted);
  --color-accent: var(--accent);
  --font-sans: var(--font-sans);
  --radius-card: var(--radius-lg);
}
```

组件只使用 Token 类（如 `bg-surface text-text`），禁止 `#123456` 散落在 JSX；例外是图片上的黑色渐变遮罩，用 Token 中的 rgba。

### 4.1 顶栏

- 高度 68px；`position: sticky; top: 0; z-index: 40`；背景 `rgba(10,10,11,0.72)` + `backdrop-filter: blur(16px)`；底部 1px `--border`。
- 左：28px 品牌标记（三笔折角形成的抽象 F / 光圈，橄榄色）+ “FrameLab” 15px/600，字距 `-0.02em`。标记用内联 SVG，不依赖图片。
- 中：导航链接“模板库”“我的作品”，13px/500，默认 `--text-secondary`，当前页 `--text` + 底部 2px 橄榄短线；hover 变亮。桌面端左对齐到品牌右侧 40px。英文为 `Templates`、`My work`。
- 右：
  - 语言切换 `LocaleSwitcher`：紧凑分段控件“中文 / English”，或 32px 圆角按钮显示 `中` / `EN`；位于登录/用户胶囊左侧，间距 12px。切换后立即更新界面文案，并触发模板与任务内容重取，不整页刷新。
  - 匿名：幽灵按钮“登录”（英文 `Sign in`；32px 高，边框 `--border-strong`）。
  - 已登录：用户胶囊按钮（头像 26px + 姓名 13px），点击打开账号弹层；不显示积分/会员。
  - 匿名点击“我的作品”时跳转 `/login?returnTo=/history`，不渲染空历史误导用户。
- 移动端：隐藏中部导航文字，只留“模板库/作品”图标 + 可访问标签；右侧保留语言切换（紧凑）与头像/登录。
- 不放置主题切换、搜索框（P0 无需求）。语言切换是 P0 明确保留的能力，不能省略。

### 4.3 语言切换

- 控件：`LocaleSwitcher` 使用 Radix ToggleGroup 或两个 32px 按钮；当前语言 `aria-pressed="true"`，容器 `aria-label` 为“切换语言 / Switch language”。
- 行为：写 `NEXT_LOCALE` Cookie（一年）→ 更新 `LocaleProvider` 与 `<html lang>` → 取消在途请求 → 失效模板/任务查询 → 重新请求。界面词典立即切换；模板与任务内容在重新请求后切换（通常 < 1 秒）。
- 切换不跳转路由、不清空登录态、不清空上传草稿；当前页面滚动位置保持。
- 切换后按钮/标签宽度变化不得导致顶栏跳动：桌面给语言控件固定最小宽度，英文导航使用 `white-space: nowrap`。
- 刷新页面从 Cookie 恢复；无 Cookie 默认中文；不根据浏览器语言自动切换。
- 语言名称固定显示为“中文”“English”，不随当前界面语言翻译（便于识别）。

### 4.2 页面容器

- `<main>` 最大宽 1440，水平内边距按断点；顶部距顶栏 48px（桌面）/32px（移动）。
- 底部留白 80px，避免最后一排卡片贴边。
- 跳到主内容链接 `.skip-link` 仅键盘聚焦时出现，位于左上角。

## 5. UI-01 模板列表

### 5.1 页面头部

- 眉题：`TEMPLATE LIBRARY / 01`（11px/600，字距 .14em，`--text-muted`）。
- 主标题：`选一个模板，开始制作`（display，中文；窄屏 h1）。
- 说明：`挑一个版式，上传照片，剩下的交给三步流水线。`（body，`--text-secondary`，最大宽 560px）。
- 英文：标题 `Choose a template`，说明 `Pick a layout, upload your photos, and let the three-step pipeline do the rest.`；字号与间距不变。
- 右侧信息（仅 ≥1024）：接口返回的模板总数（当前 `10 个模板`，等宽数字）与一条细线，不用卡片包起来；英文为 `10 templates`。
- 头部下间距 32px；分类栏下间距 24px。

### 5.2 分类栏

- 横向可滚动；不换行；右侧渐隐遮罩提示可滚动；隐藏滚动条但保留键盘与触控滚动。
- 胶囊：高 34px，水平内边距 14px，圆角 full，13px/500，边框 1px；默认 `--surface`/`--text-secondary`；hover 边框 `--border-strong`、文字 `--text`；选中 `--accent-soft` 背景 + `--accent-border` 边框 + `--accent` 文字。
- 顺序：全部、旅行风景、创意图片、节日营销、人像写真、生活记录、电商海报。
- 分类列表来自 `GET /api/template-categories`，按 `sortOrder` 渲染；前端只把“全部”置顶，不写死分类名称。当前名称仅为本设计的种子示例。
- 选中态变化只切换筛选，不整页刷新；列表切换时保留滚动位置，列表顶部淡入 160ms。
- 键盘：Tab 聚焦胶囊，Enter/Space 选择；`aria-pressed` 标识选中。

### 5.3 卡片网格

- `display:grid; grid-template-columns: repeat(auto-fill, minmax(180px, 1fr)); gap: 20px;`
  - 1440 内容区约 6 列；1280 约 6 列；1024 约 4 列；768 约 3 列；480 约 2 列；360 约 1～2 列（由最小宽决定）。
- 卡片：3:4 比例，圆角 20px，`overflow:hidden`，背景 `--surface`，边框 1px `--border`；整卡为 `<Link>`。
- 封面：`object-fit: cover`；默认 `scale(1)`；hover/focus 时 `scale(1.035)`，持续 320ms `--ease-out`。
- 底部遮罩：`linear-gradient(180deg, transparent 42%, rgba(0,0,0,.78) 100%)`，高度 55%。
- 信息层（距底 16px、左右 16px）：
  - 标题 14px/500 白；最多两行，超出省略（中文通常一行，英文允许两行）。
  - 元信息 12px：`2 张素材` + 分隔点 + 分类名，颜色 rgba(255,255,255,.72)。
- 左上角分类小标签（可选）：11px，深色半透明底，圆角 full，不抢标题。
- 右上角圆形箭头按钮：36px，`--accent` 背景 + 深色箭头；默认 `opacity:0; translateY(4px)`；hover/focus 显现；仅视觉，点击仍由整卡链接处理。用 `<span aria-hidden="true">` 渲染，不嵌套 `<button>`，避免交互元素嵌套。
- 卡片 hover：边框 `--accent-border`，`translateY(-2px)`，阴影 `--shadow-card`；focus-visible：2px 橄榄外环，offset 2px。
- 图片 `loading="lazy" decoding="async"`，容器固定比例防抖动；加载时显示 `--surface-2` 骨架微光。
- 空状态：占满一行的面板，居中；线性图标（图层/相框），标题“这个分类还没有模板”，说明“换一个分类，或查看全部模板”，次按钮“查看全部”。
- 错误状态：面板 + “模板暂时加载失败” + “重新加载”（主按钮）。
- 加载状态：头部文字骨架 + 6 张卡片骨架（图片区 shimmer，底部两条短条）。

- 详情加载中：左栏显示封面/标题/要求骨架，右栏历史待左栏就绪后加载；不显示可点击 CTA。
- 模板不存在或已下架：整页空态“模板不存在或已下架” + 主按钮“返回模板库”；请求失败：面板显示“模板暂时加载失败” + “重新加载”，不渲染空的上传区。

### 6.2 左栏：模板与上传

- 封面：圆角 16px，边框 1px，比例由 `canvas` 决定（4:3 或 3:4），`object-fit: cover`；下方 20px 间距。
- 分类胶囊（只读，小号）+ 标题（h1 26～32px）+ 描述（body，`--text-secondary`，最多 2 行，超出省略但不藏关键信息）。
- 要求行：三个信息块横排或换行：
  - `2 张图片`
  - `JPG / PNG`
  - `每张 ≤ 5 MB`
  - 用 12px、`--text-muted`，块之间用 1px 竖线或 12px 间距；不单独做成大卡片。
- 上传标题行：`上传素材`（h3）+ 右侧 `0 / 2`（mono，完成时 `--accent`）。
- 匿名状态：槽位显示锁图标 + `登录后上传`，整个槽位点击跳转登录并带 `returnTo`；不打开文件选择器，避免产生无法提交的本地草稿。
- 上传位网格：2 列（`requiredImageCount=1` 时单列，最大宽 220px；3 张时第一张跨两列作为主图，后两张各占一列，与结果版式“上一下二”对应）。空态用 `<label>` + 隐藏 `<input type="file">` 触发选择；填充态容器用 `<div>`，替换/移除是独立按钮，避免交互元素嵌套。每个槽位：
  - 比例 4:3，圆角 14px，边框 1px dashed `--border-strong`，背景 `--surface`。
  - 空态：居中的 `ImagePlus` 线性图标（24px，`--text-muted`），主文案 `点击或拖入图片`（13px），辅助 `JPG/PNG · ≤5MB`（11px `--text-muted`），左上角序号 `01`（mono 11px）。
  - hover：边框 `--accent-border`，背景 `--accent-soft`（5%），图标变 `--accent`。
  - 拖拽经过：同 hover + 2px 内描边；`aria` 提示可放置。
  - 已选本地文件：立即显示预览（object-fit cover），底部半透明条显示文件名（截断）与大小；右上角三个 32px 图标按钮：替换、移除；hover 显示，键盘始终可聚焦。
  - 上传中：图片 60% 不透明 + 中央 36px 进度环（accent）+ 百分比（mono 11px）；底部文案“上传中”。
  - 上传失败：图片 40% 不透明 + 珊瑚色 1px 边框；中央“重试”按钮；可移除；错误原因通过顶部 toast 呈现。
  - 校验失败（本地）：不进入上传；槽位显示珊瑚边框；错误原因通过顶部 toast 呈现，不在槽位下方增加占位文案。
  - 已上传：右下角 20px 成功对勾（success）；仍可替换/移除。
- 文件大小/类型：前端即时校验；采用模板接口返回的 `maxFileSizeBytes` 与 `acceptedMimeTypes`；不要写死 5MB。
- 主按钮：
  - 高 48px，圆角 14px，全宽；背景 `linear-gradient(180deg, var(--accent-hover), var(--accent) 55%, var(--accent-pressed))`；文字 `--accent-ink` 14px/600；阴影内高光 `inset 0 1px 0 rgba(255,255,255,.35)`。
  - 默认文案 `开始制作`，右侧箭头 16px，间距 8px；英文 `Start creating`；hover 上移 1px/亮度 +3%；active 下压 1px；focus-visible 外环。
  - 未满足条件：背景 `--surface-2`、文字 `--text-disabled`、无阴影；下方 12px 说明缺什么（“还差 1 张图片”）。
  - 提交中：按钮内 16px spinner + `正在提交…`，禁用；不接受重复点击。
  - 幂等：点击时生成 `clientRequestId`，同一次提交的网络重试复用同一个值；收到 202/200 后清空，下一次主动制作生成新值。网络错误时按钮显示“重试提交”，仍复用原值。
  - 被受理：按钮立即恢复为可用态；清空上传位与本地草稿（保留模板与预览），避免用同一组素材重复提交；出现 toast“任务已创建”，右栏插入新卡并短暂高亮 600ms。不要继续显示“提交中”。
  - 匿名：按钮文案 `登录后开始制作`；点击跳转 `/login?returnTo=/templates/{id}`。
- 上传草稿不跨页面保存；离开时若仍有已上传未提交素材，弹确认（“离开后本次选择会丢失”），避免无提示丢弃。P0 可用浏览器 `beforeunload` 仅在上传/提交中拦截。

### 6.3 右栏：制作记录

- 头部：`制作记录`（h2 22px）+ 数量（small muted）+ 右侧 36px 刷新图标按钮（有旋转 320ms，不用持续转圈）；刷新按钮 `aria-label="刷新制作记录"`。
- 右栏展示当前模板最近 20 条任务；更早的活跃任务在历史页“进行中”筛选继续跟踪，避免右栏无限增长。
- 网格：`repeat(auto-fill, minmax(240px, 1fr))`，间距 16px；1440 下通常 3 列，1024 下 2 列，移动 1 列。
- 卡片统一 3:4、圆角 18px、`--surface`、1px 边框；点击打开任务详情弹层；键盘 Enter/Space 同等。
- 卡片状态（同时用图标+文字+颜色）：

| 状态 | 视觉 | 卡片内容 | 操作 |
|---|---|---|---|
| `QUEUED`（首次） | 模板封面 12% 可见 + 深色遮罩 | 时钟图标 + “排队中” + `等待工作线程` + 创建时间 | 查看详情 |
| `QUEUED`（`resumeCount>0`） | 同上 + 顶部 2px 琥珀细线 | “正在恢复” + `服务重启，将从断点继续` + 当前阶段 | 查看详情 |
| `RUNNING` | 模板封面 18% 可见 + 顶部微光扫过（reduced-motion 关闭） | 三步节点（当前节点橄榄色脉冲）+ 当前阶段文案 + 第 N 次尝试 + 已用时 | 查看详情 |
| `RETRYING` | 深色底 + 2px 琥珀线 + 缓慢呼吸的等待图标（reduced-motion 关闭） | “等待重试” + 失败阶段 + `已尝试 1/3 次` + 最近失败原因（1 行）+ 预计几秒后重试 | 查看详情 |
| `SUCCEEDED` | 结果图铺满 | 右上角 success 对勾；底部渐变 + “已完成 · 14:32” + hover “查看结果” | 打开结果预览 |
| `FAILED` | 深色底 + 顶部 2px 珊瑚线 | 珊瑚图标 + 阶段名 + 原因（2 行截断）+ 尝试次数 + 创建时间 | 打开任务详情 |
| 查询异常（列表级） | 不改变卡片状态 | 顶部常驻 warning toast：“任务状态暂时无法更新” + `重试`；活跃卡片右上角 amber 小点 | 手动重试 |
| 空 | 面板占满右栏高度 320px | “还没有制作记录” + “上传素材后开始第一个任务” | — |

- 阶段节点：三个 6px 圆点 + 连线；已完成为 success，当前为 accent + 1.2s 脉冲，未完成为 `--border-strong`。节点下只显示当前阶段文字，不铺三段长文案。
- 重试倒计时不要每秒闪烁；优先显示服务端 `nextRetryAt` 推导的“约 N 秒后”，超过 30 秒显示具体时间；前端不得据此改变任务状态。
- `RETRYING` 仍算活跃任务，卡片保留在列表顶部区域并继续轮询；不要显示“失败”终态样式。
- 卡片底部信息：模板标题（13px/500）+ 创建时间（11px mono muted）。成功卡底部显示结果时间；失败/等待重试卡显示尝试次数。
- **不提供**删除、重做、下载按钮；失败卡也不提供“重新执行”，避免与范围冲突。
- 查看详情弹层（`TaskDetailDialog`）：最大宽 880px，左侧结果图/封面，右侧步骤时间线、失败原因、素材缩略图、任务短码；每个步骤可展开尝试历史（`AttemptList`），显示尝试序号、状态、时间、错误码与本地化原因；关闭按钮 + Esc；焦点返回触发卡。

### 6.4 结果预览

- 使用 Radix Dialog；遮罩 `rgba(0,0,0,.72)` + `backdrop-filter: blur(6px)`；面板半径 24px，`--surface`，1px 边框，`--shadow-panel`。
- 图片 `object-fit: contain`，最大高 70vh；背景 `--bg`；四周 24px。
- 顶部：模板标题 + 完成时间（mono）+ 关闭按钮；底部：`1600 × 1200 · 2.4 MB` + 任务短码；不提供下载。

## 10. 多任务与历史列表（交互细节）

- 同一列表只保留一个轮询器：以“当前查询”状态决定是否刷新；不按卡片创建定时器。
- 新任务受理后：`invalidateQueries(['tasks', userId, ...])`；新卡插入顶部，600ms 高亮描边后消失。
- 轮询响应按任务 ID 合并：只更新同一 ID 的卡片；不得用整页响应覆盖另一个账号或另一模板的缓存。
- 终态任务：立即停止该任务的自动跟踪；若列表仍有活跃任务（含 `RETRYING`），轮询继续。
- 页面隐藏：浏览器 `visibilitychange` 时 TanStack Query 自动暂停 interval；回到前台执行一次 `refetch`。
- 切换账号：取消进行中的请求、清空 QueryClient、释放所有 Blob URL、重置上传草稿、跳转首页。
- 切换语言：写 Cookie、更新 Provider 与 `<html lang>`、取消旧语言请求、清空模板/任务缓存并重取；不重置上传草稿与登录态。
- 查询失败：卡片保留最后快照；活跃卡显示 amber 点 + 顶部 amber 常驻 toast；用户点“重试”才重新请求；恢复后 toast 自动消失。
- 查询失败与任务失败必须区分：查询异常卡片保留原状态（如“等待重试”），只加 amber 点；不得显示“失败”或“重试耗尽”。
- 任务详情弹层关闭：取消该任务的单任务轮询；不影响列表轮询。

### 11.2 文案规则

- 句子短、动词开头；不用感叹号、不用“魔法/AI 一键”等夸张词。
- 错误必须说明**发生了什么 + 下一步**：如“图片超过 5 MB，请压缩后重试”，而不是“上传失败”。
- 时间：今天显示 `HH:mm`；昨天显示 `昨天 HH:mm`；更早显示 `MM-DD HH:mm`；跨年显示 `YYYY-MM-DD`。英文使用 `Today HH:mm` / `Yesterday HH:mm` / `MMM D, HH:mm`，由 `Intl` 生成。
- 数字与单位之间加空格：`5 MB`、`1600 × 1200`、`2 张`；英文用 `2 photos`、`1600 × 1200`；数字用 `Intl.NumberFormat`。
- 阶段中文名固定：素材检查 / 模拟生成 / 结果整理；英文：Material check / Generate / Finalize。
- 状态中文名固定：排队中 / 正在恢复 / 处理中 / 等待重试 / 已完成 / 失败；英文：Queued / Resuming / Processing / Retrying / Completed / Failed。
- 失败原因来自 API，禁止前端把错误码直接展示给用户；错误码只出现在尝试历史的 mono 小字中。
- 重试次数：处理中显示“第 N 次尝试” / `Attempt N`；等待重试显示“已尝试 N/M 次” / `Attempt N of M used`；不要显示百分比或剩余时间倒计时到毫秒。

| `Chip` | default / selected / disabled | 高 34；`aria-pressed` |
| `TemplateCard` | skeleton / default / hover / focus | 3:4；整卡链接；标题遮罩；英文最多两行 |
| `UploadSlot` | empty / filled / uploading / error / uploaded | 4:3；文件输入隐藏但可键盘触发；进度 `role=progressbar` |
| `TaskCard` | queued / resuming / running / retrying / success / failed / stale | 3:4；状态四要素；无删除/重做 |
| `StageStepper` | pending / active / done / failed / skipped | 3 节点；当前脉冲；reduced-motion 关闭 |
| `AttemptList` | collapsed / expanded / empty | 尝试序号、状态、时间、错误码、本地化原因；`INTERRUPTED` 单独标注 |
| `RetryBadge` | waiting / exhausted / none | `第 N/M 次尝试`；等待时显示下次重试时间 |
| `StatusBadge` | neutral / running / retrying / success / danger / warning | 图标 + 文案；底色 10%；不只用颜色 |
| `Dialog` | open / loading / error | Radix；焦点陷阱；Esc；返回焦点 |
| `LocaleSwitcher` | zh-CN / en-US / compact | 32px 高；`aria-pressed`；写 Cookie；不跳路由 |
| `Toast` | success / error / info / warning | 顶部居中、顶栏下方 76px，宽 420px；success/info 4s，error 6s，warning 常驻；可关闭；可带操作按钮；`aria-live` |
| `EmptyState` | — | 图标 + 标题 + 说明 + 可选动作 |
| `ErrorState` | — | 同上，主按钮“重新加载” |
| `Skeleton` | card / line / circle | 微光扫过；不做布局跳动 |
| `Avatar` | initial / image | 32/64；橄榄底 |
| `Pagination` | prev / page / next / disabled | 40px 目标；当前页强调 |

所有交互组件必须有 `focus-visible` 样式；图标按钮必须有 `aria-label` 或可见文字；上传文件输入使用 `<input type=file>` + `<label>`，不伪造点击区域。

## 13. 响应式

| 断点 | 布局 |
|---|---|
| ≥1280 | 列表 6 列左右；制作台 400px + 1fr；历史 4 列 |
| 1024～1279 | 列表 4～5 列；制作台 380px + 1fr；历史 3 列 |
| 768～1023 | 列表 3 列；制作台单列（先左后右）；历史 2 列 |
| <768 | 列表 2 列（360 下 1～2 列）；单列制作台；历史 1 列；顶栏精简 |
| <1024 的制作台 | 底部 sticky CTA：背景 `rgba(10,10,11,.9)` + blur；上边框；按钮全宽；`padding-bottom: env(safe-area-inset-bottom)` |

- 不允许横向滚动（分类栏内部滚动除外）。
- 触控目标 ≥44×44px（视觉可 36px，热区补足）。
- 输入框在移动端 16px 字号，避免 iOS 自动缩放。
- 英文界面在 360px 下必须完成浏览、上传、提交与查看结果：顶栏语言控件用 `中/EN` 紧凑形态，卡片标题两行，按钮文字允许换行但不溢出。

## 14. 无障碍

- 语义结构：`header` / `nav` / `main` / `aside` / `footer`；标题层级不跳级。
- 跳转主内容链接；键盘可达所有功能。
- 焦点可见：2px `--accent` 外环 + 2px offset；禁止 `outline:none` 无替代。
- 状态变化：任务卡状态容器 `role="status" aria-live="polite"`；错误 `role="alert"`；避免每次轮询都重复播报（仅状态/阶段变化时更新文案）。
- 图片：模板封面 `alt="${title} 模板封面"`；结果 `alt="${title} 制作结果"`；纯装饰图标 `aria-hidden`。
- 上传：每槽位 `aria-label="第 1 张素材，未选择"`；上传进度 `aria-valuemin/max/now`；替换/移除按钮有明确标签。
- 弹层：Radix 自动焦点陷阱；关闭后焦点返回触发元素；打开时锁滚动。
- 颜色对比：正文 ≥ 4.5:1，大字 ≥ 3:1；强调按钮使用深色文字；状态不只靠颜色。
- 语言：`<html lang>` 随语言切换；切换按钮 `aria-pressed`；`aria-label` 使用双语（“切换语言 / Switch language”）；状态播报使用当前语言，切换语言后清空并重新建立 live region，避免重复播报。
- 动效：`prefers-reduced-motion: reduce` 时关闭图片缩放、脉冲、微光扫过、重试呼吸，仅保留 100ms 淡入。
- 键盘：Esc 关闭弹层；Enter/Space 触发卡片与按钮；Tab 顺序符合视觉顺序。

## 16. 素材与图片规范

| 类型 | 规格 |

## 17. 实现注意

- 页面默认 Server Component 负责 metadata 与静态外壳；交互区使用 Client Component；禁止用 Server Action 写任务或持久化。
- 图片运行时来自 Java，使用原生 `<img>`（或 `next/image` 的 `unoptimized`），避免为动态主机配置构建期白名单。
- 所有 API 类型集中在 `features/*/types.ts`，与 [04](04-api.md) 一一对应；禁止在组件里散落字符串枚举。
- 状态颜色、阶段文案、错误文案从映射表读取，不写 if/else 长链；状态文案从 i18n 词典读取，失败原因直接用 API 的 `message`。
- 词典键在 `zh-CN.ts` 定义，`en-US.ts` 必须同键；构建期类型检查缺键。模板标题、描述、分类名不进入词典，来自 API。
- 查询键带 `locale`；语言切换时取消在途请求并清空相关缓存，上传草稿与登录态保留。
- 组件测试选择器使用稳定的 `data-testid`：`template-card`、`upload-slot`、`task-card`、`task-status`、`query-error-banner`、`locale-switcher`、`attempt-list`。
- 不在前端计算任务进度百分比；阶段节点只表达三步位置。
- 不在前端保存任务历史；刷新后从 API 恢复。
- 不在前端把 `nextRetryAt` 换算成新的任务状态；重试倒计时只是展示，状态始终以服务端为准。
